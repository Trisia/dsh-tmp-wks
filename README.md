# dsh-tmp-wks

![demo](docs/demo.en.gif)

## Why this plugin?

Because throwing together a quick piece of throwaway work meant leaving DSH, creating a
directory by hand, and coming back in — and reusing the same directory every time made
the contents contaminate each other.

## Install

Creates a throwaway workspace with one click and starts a session in it:

```sh
dsh plugin --profile web add dsh-tmp-wks
```
